# Prodigy_ML_02
Create a K-means clustering algorithm to group customers of a retail store based on their purchase history.


Binary Classification Model (Logistic Regression / SVM)

This repository contains my submission for Task 02 of the Prodigy InfoTech 
Machine Learning Internship. The task focused on building a classification model 
and understanding how accuracy changes based on preprocessing and feature scaling.

I used a sample dataset and tried two approaches – Logistic Regression and SVM. 
Both models were compared based on their accuracy, confusion matrix, and 
precision/recall values.

---
Key Highlights
- Cleaned and standardized the dataset  
- Trained a Logistic Regression classifier  
- Trained an SVM classifier  
- Compared both models  
- Included observations on model performance
